## Graceful Fallback Guarantee
All `<img>` elements feature an integrated `onerror` trigger that mounts an inline institutional SVG vector crest and `#0B192C` gradient background in real time, preventing broken image indicators and Cumulative Layout Shift (CLS) if any image file is absent.
